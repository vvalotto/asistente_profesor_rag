# Asistente Profesor Virtual RAG para Ingeniería de Requerimientos

Este proyecto implementa un asistente virtual basado en RAG (Retrieval Augmented Generation) para facilitar el aprendizaje de procesos de requerimientos de software para estudiantes de ingeniería.

## Componentes principales

- Sistema de ingesta y procesamiento de materiales educativos
- Sistema de recuperación de información relevante
- Sistema de generación de respuestas pedagógicas
- Interfaz para interacción con estudiantes
- Sistema de evaluación y mejora continua

## Configuración

1. Clonar el repositorio
2. Instalar dependencias: `pip install -r requirements.txt`
3. Configurar variables de entorno en el archivo `.env`
